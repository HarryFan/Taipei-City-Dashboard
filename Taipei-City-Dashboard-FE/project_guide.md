# 雙北黑客松專案開發指南：犯罪熱點房價分析

## 🧠 專案主題簡介

本專案為 2025 雙北黑客松設計，主題為「安心住宅地圖」，透過整合雙北地區的**治安熱點資料**與**房價資訊**，協助民眾與政府掌握高風險區域與房市變化趨勢。

## 🧩 開發目標與組件設計

### ✅ 開發 4 個雙北組件（含至少 1 個地圖圖層）

| 組件名稱 | 功能 | 備註 |
|----------|------|------|
| 犯罪熱點地圖組件 | 顯示雙北地區各類型犯罪事件熱區，使用 Mapbox | ✅ 含地圖圖層 |
| 房價趨勢圖表 | 各行政區房價變化（線圖） | 使用 VueApexChart |
| 治安 vs 房價對照圖 | 同時呈現案件數與房價變化（柱狀圖或熱力圖） | 支援互動切換 |
| 安心居住指數雷達圖 | 綜合風險＋房價資訊，給予住宅評等建議 | 可為創新模組 |

## 🛠️ 技術架構與說明

### 前端技術棧

- Vue 3 + Vite
- Pinia 狀態管理
- VueApexChart (只能用此圖表套件)
- Mapbox 地圖圖層
- Tailwind SCSS + Google Material Icons

### 前端關鍵元件範例

#### HistoryChart.vue 功能說明

- 時間序列圖表元件，可用來顯示月度房價或案件數趨勢
- 支援多筆資料切換（按鈕控制）

### 客製化元件建議

可根據 HistoryChart 範本製作：
- PriceHistoryChart.vue
- CrimeTrendChart.vue

## ⚙️ 專案啟動與資料來源

### 本地開發建議

1. Fork 並 clone 專案：https://github.com/taipei-doit/Taipei-City-Dashboard
2. 啟動 FE 專案（Vue）

```bash
cd Taipei-City-Dashboard-FE
npm install
npm run dev
```

3. 可搭配本地假資料模擬組件，避免初期卡在後端串接

### 合法開放資料來源

- 警政署開放資料：https://data.gov.tw/dataset/11892
- 實價登錄資料平台：https://plvr.land.moi.gov.tw/DownloadOpenData
